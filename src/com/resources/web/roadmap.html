Where the Server Is Headed

The plan · September 2026

This project is a learning journey: build a real HTTP server by hand, then layer on features one at a time. Here is the roadmap we are following.

Done So Far

Raw socket handling, one thread per connection, HTTP request parsing (GET/HEAD), safe static file serving with path-traversal protection, correct Content-Type for common files, and default headers on every response. All of it is unit-tested.

Next Up

Support for request bodies, which unlocks POST, PUT, and DELETE. From there we can add real routing and a small JSON REST API backed by the Jackson library already sitting in lib/.

Eventually

A simple browser frontend to exercise the API, and maybe request logging with the SLF4J setup that is already wired in. The goal is to reach a point where the server can serve a useful site end to end.

"Building it by hand first makes every framework you meet later feel like magic you can peek under."
