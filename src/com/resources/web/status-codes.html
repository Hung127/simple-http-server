HTTP Status Codes

The language of outcomes · September 2026

After processing a request, the server returns a three-digit status code that tells the client how it went. Our server models these in the HTTPStatusCode enum, each carrying a numeric code and a human-readable message.

Success: 200

Everything worked. The server found the requested file and is sending it back. This is the response you see when loading any of the pages on this site.

Client Errors: 400, 401, 414

These mean the request itself was malformed or impossible. A 400 Bad Request appears when the request line is malformed or headers are invalid. 414 URI Too Long guards against oversized request targets.

Server Errors: 500, 501, 505

These indicate the server could not fulfill an otherwise valid request. 500 Internal Server Error flags an unexpected failure handling a file. 501 Not Implemented is returned for methods we do not support yet. 505 HTTP Version Not Supported rejects requests from an unknown protocol version.

"A good status code turns a vague failure into an actionable one."
